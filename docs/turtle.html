🐢 海龟交易法则

Donchian Channel Breakout + ATR Stop Loss — 突破买入 / 通道退出 / ATR止损

📋 策略原理

海龟交易法则诞生于1983年，由理查德·丹尼斯设计。其核心是趋势跟踪——在价格突破近期高点时买入，跌破近期低点时卖出，用ATR波动幅度控制风险。策略不预测方向，而是在趋势发生后跟随，"截断亏损，让利润奔跑"。

价格超过过去 N 日最高价 → 买入信号，捕捉趋势启动

🔹 通道退出

价格跌破过去 M 日最低价 → 卖出信号，趋势结束时离场

🔸 ATR 动态止损

价格跌破"入场价 - 2×ATR" → 止损离场，控制单笔最大亏损

退出机制 2

三套通道参数

短期 DC(10, 5) + ATR(10)
中期 DC(20, 10) + ATR(20)
长期 DC(30, 15) + ATR(20)

ATR 止损公式

TR = max(当日振幅, 跳空高开, 跳空低开)
ATR = TR 的 N 日均值
止损价 = 入场价 - 2 × ATR

💡 策略总结与使用心得

核心发现

  • 短期 DC(10,5) 在两只标的上全面领先：回报、夏普、回撤均最优
  • 中芯国际短期策略 +1401.73%，是买入持有的 8.4 倍，超额收益 +1234%
  • 高波动标的（ATR 5-8%）远胜低波动标的（ATR 2.6%），海龟法则天生适合高波动
  • 长期 DC(30,15) 止损率高达 50%，震荡市中假突破频繁，不适合低波动标的
  • 胜率与盈亏比呈反向关系：中芯国际短期胜率仅 32%，但盈亏比 4.8，"低胜率高盈亏比"

适应场景

  • 适合：强趋势市场、高波动标的、中长线投资、多标的组合、商品期货
  • 不适合：横盘震荡市、低波动蓝筹股、高频交易、政策驱动 V 型反转

实操建议

  • 优先选择 ATR/价格 > 3% 的高波动标的
  • 短期通道 DC(10,5) 优先，交易频繁但收益最优
  • 止损不可省略——长期策略止损率 50% 看似"老是止损"，但正是止损避免了更大亏损
  • 建议与均值回归策略组合使用，形成"趋势 + 震荡"互补
  • 海龟策略可能连续 5-8 笔亏损，耐心和纪律是核心竞争力
